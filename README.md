# Xixo Inglés

App para aprender inglés en iPhone/iPad (PWA), estilo Duolingo: audio, frases con fichas, situaciones, pronunciación, vidas, XP, racha y repaso espaciado. Funciona sin internet.

**Instalar:** abre la URL de GitHub Pages en Safari → Compartir ⬆️ → *Añadir a pantalla de inicio*.

Las frases están en `phrases.js`.
